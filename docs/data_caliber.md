# 数据口径说明 · 一分一段表（T02）

> 适用范围：`data/cleaned/score_segments.csv` 与后续入库/位次换算。
> 红线：**累计人数 = 位次上限，同分并列取累计值**；任何缺失分数段必须标注，绝不补造。

## 一、一句话口径

广东省教育考试院每年发布的《普通高考成绩各分数段数据》表中，**「累计人数」= 该分数及以上考生总数**，即拿到该分数的考生在全体中的**最差（最大）名次 = 位次上限**。同一分数内部的名次差异无法从公开表得知，因此**同分并列统一取累计值**作为位次。

| 字段 | 含义 | 示例（2026 物理） |
|---|---|---|
| `score` | 文化总分（整数分，含官方口径加分） | 699 |
| `rank` | 本科口径「累计人数」（= 位次上限） | 20 |

## 二、数据范围与来源

- 省份：广东（新高考 3+1+2）
- 年份：**2024 / 2025 / 2026**（普通类 历史、物理 两个科类，共 6 张表，3503 行）
- 来源：广东省教育考试院官网《关于公布广东省XXXX年普通高考成绩各分数段数据的通知》附件，原件留档于 `data/raw/<year>/`，来源清单 `data/raw/sources.json`

| 年份 | 官方公告页 |
|---|---|
| 2024 | https://eea.gd.gov.cn/zwgk_tjxx/content/post_4445715.html |
| 2025 | https://eea.gd.gov.cn/zwgk_tjxx/content/post_4734449.html |
| 2026 | https://eea.gd.gov.cn/tzgg/content/post_4916194.html |

> 年份口径说明：T02 任务卡要求 2024/2025/2026 三年；2023 年官方原件为**扫描 PDF（无文字层）**，若强行 OCR 存在数字错读风险、违反「不编造数据」红线，故 MVP 仅将 2023 原件留档于 `data/raw/2023/`，**不进入清洗数据集**。如需补充可在后续用 OCR + 人工复核流程扩展。

## 三、为什么用「本科」累计列

官方表每行含 本科/专科 两套「分数段人数 + 累计人数」（加分口径不同，个别人群本科与专科加分不同）：

```
文化总分 | 本科：分数段人数(含本科加分) 累计人数 | 专科：分数段人数(含专科加分) 累计人数
```

- 本产品主推**本科批次志愿**，位次统一采用**本科（含本科加分）累计人数**。
- 两列在个别分数上有差异（例：2026 物理 102 分，本科累计 433353 vs 专科累计 433354），混用会导致位次换算偏差，故口径固定为本科列并在下游禁止混用。

## 四、边界处理（重要）

1. **顶部聚合段**：表首行为「XXX（含以上）」（如「699（含以上）」），代表该分数及以上全部考生。CSV 只记 `score=XXX, rank=累计值`；分数高于 XXX 的用户位次也取该累计值（官方未细分，属公开数据上限）。
2. **底部下限**：表末行为 100 分。100 分以下的分数官方未逐分公布，**位次换算对 <100 分返回「无细分数据」**（不虚构）。
3. **零人段**：官方逐分列出（含 0 人段，如 2026 历史 668 分 0 人、累计不变），CSV 原样保留，位次单调检查允许相邻分数累计相等。

## 五、缺失与 gap 标注

- 官方表每个整数分数都有一行，因此**正常不应有缺失**。
- 清洗脚本对每个 (年份, 科类) 检查 `floor..top` 全区间：任何缺失分数写入 `data/cleaned/gaps.json`（含缺失分数列表），CSV 只保留真实提取行，**绝不补造位次**。
- 当前产出：gaps.json 为 0 组缺口（6 张表覆盖率均 100%）。

## 六、校验与抽查

- `scripts/validate_data.py`（自动）：分数逐分单调、位次非增、覆盖率 ≥ 95%、边界合法、官方抽查值回归。
- J1 抽查（人工/独立复核）：每年每科类独立从 PDF 文字层抽取 10 条比对，共 60 条全部与官网一致，0 失败（2026-10-14 复核）。

## 七、下游使用约定

- T04：按 (province, year, subject_type, score) 入库，建索引。
- P1 位次换算：给定 (year, subject_type, score) → `rank`；给定位次反查分数取累计区间下界。
- 评测隔离不变：一分一段表仅用于位次换算；回测的训练/验证按年份切分，不跨口径。

# 数据口径说明 · 投档线（T03）

> 适用范围：`data/cleaned/admission_lines.csv`、`data/cleaned/universities.csv` 与后续「冲稳保」推荐。
> 红线：**投档线 ≠ 录取线**；官方标注「-」的行保留但分数/排位置空，**绝不补造**；同名院校按院校代码严格区分，不混用。

## 一、一句话口径

「投档线」= 广东省教育考试院《本科批次正式投档情况》公布的**专业组投档最低分与投档最低排位**。
它是「院校 + 专业组」级别的最低门槛，**不等于任何具体专业的录取分数线**。MVP 阶段推荐引擎只用投档线做基线，专业级录取线不在本期范围。

| 字段 | 含义 | 示例（2026 物理 北大 205 组） |
|---|---|---|
| `min_score` | 投档最低分（文化总分） | 690 |
| `min_rank` | 投档最低排位（同分内部排序后的实际位次） | 110 |

> 重要：`min_rank` 是**同分考生内部再排序后的具体位次**，同一分数下不同专业组的投档排位可以不同（属官方真实数据）；
> 一分一段表的「累计人数」只是该分数的**位次上限**。因此校验时要求排位落在该分数的合法区间（更高分累计+1 ≤ 排位 ≤ 本分累计），而不是「同分同位次」。

## 二、数据范围与来源

- 省份：广东（新高考 3+1+2），普通类 **历史、物理** 两个科类，本科批次正式投档
- 年份：**2024 / 2025 / 2026**，共 6 张表，**15868 行投档记录、1095 所院校（院校代码唯一）**
- 来源：广东省教育考试院官网 **ptgk（普通高考）栏目**公告附件 PDF，原件留档于 `data/raw/admission/<year>/`，来源清单 `data/raw/sources.json`（键前缀 `admission/…`）

| 年份 | 官方公告页 | 附件 |
|---|---|---|
| 2024 | https://eea.gd.gov.cn/ptgk/content/post_4458330.html | ZIP（内含历史/物理两 PDF） |
| 2025 | https://eea.gd.gov.cn/ptgk/content/post_4746781.html | 附件1=历史、附件2=物理 |
| 2026 | https://eea.gd.gov.cn/ptgk/content/post_4926622.html | 附件1=历史、附件2=物理 |

> 公告另有 9 个附件（含艺体类等），只取普通类历史/物理，其余不入库。

## 三、表结构

`admission_lines.csv`（每条 = 院校代码 + 专业组代码 + 年份 + 科类）：

| 字段 | 含义 |
|---|---|
| `year` / `province` / `subject_type` | 2024/2025/2026 · 广东 · 历史/物理 |
| `university_code` / `university_name` | 院校代码 / 完整规范名（含校区后缀） |
| `group_code` | 专业组代码 |
| `plan_count` / `admitted_count` | 计划数 / 投档人数 |
| `min_score` / `min_rank` | 投档最低分 / 投档最低排位（官方为「-」时置空） |

`universities.csv`（唯一院校清单，按院校代码）：

| 字段 | 含义 |
|---|---|
| `university_code` / `university_name` | 院校代码 / 完整规范名（含校区后缀） |
| `base_name` | 去括号后缀的基础校名（用于同名分组） |
| `province` / `school_type` / `tags` | 省份 / 类型 / 985、211、双一流标签 |
| `meta_status` | 已核 / 待补 |

## 四、清洗规则（重要）

1. **渗字处理**：PDF 左侧竖排「广东省教育考试院」会渗入单元格。
   - 数值列：取单元格内**第一个数字**（如「院509」→「509」）。
   - 名称列：`省教育考试院` 等安全渗字**必删**；`广`/`东` 属歧义渗字，**仅当去掉后仍是该院校代码的已知变体才删**，以保护「广东/东北/东南/广西」等真实校名。
2. **规范名选择**：每个院校代码的候选变体中，**优先取无括号后缀的纯校名**（如 `哈尔滨工业大学` 而非 `哈尔滨工业大学(中外合作办学)`），无纯名时取频次最高的完整名（如 `华北电力大学(北京)`、`中国地质大学(武汉)`，用于校区区分）。
3. **同名院校（校区/分部）**：不同院校代码即使基础校名相同也**绝不混用**（如哈工大本部 `10213` / 深圳 `18213` / 威海 `19213`；华电北京 `10054` / 保定 `10079`）。同名清单输出到 `data/cleaned/university_name_audit.txt` 供人工核对，当前 14 组。
4. **空投档线**：官方最低分/排位为「-」的行保留，`min_score`/`min_rank` 置空（当前 12 行），不补造。
5. **元数据**：985/211/双一流 按教育部官方名单（985=39、211=112、双一流=147 含校区条目）以基础校名匹配；省份按校区覆盖表优先；广东本省院校单独人工核对。当前 **394 所已核、701 所待补**，待补院校供下游按需补充，绝不臆造。

## 五、校验与抽查

- `scripts/validate_data.py`（自动）：投档行唯一性、枚举合法性、排位落在分数区间、排位不超过当年/科类总人数、院校代码关联、官方抽查值回归（11 条）、院校元数据完整性。
- `scripts/spotcheck_admission.py`（J1 独立抽查）：不复用清洗结果，重新从 PDF 抽取 20 所知名院校（北大/清华/复旦/上交/浙大/南大/中科大/哈工大/武大/华科/中大/华南理工/深大/广工/华南师范/暨大/南方科技/广州大学/广外/深圳技术）三年原始行比对，0 失败。

## 六、下游使用约定

- T04：按 (year, subject_type, university_code, group_code) 入库，建索引。
- 「冲稳保」推荐：以近三年投档最低排位为基线，结合用户位次换算（T02）计算冲/稳/保区间；专业组级投档线仅作门槛参考。
